# Update 12: Belt snapping, upgrades, and demolition

- Conveyor run endpoints snap to source outlets, press inputs, and existing belt endpoints.
- Connected segments now transfer moving dust items into the press.
- Presses and extractors show measured throughput in items per minute in their E interaction panel.
- The build menu reports current conveyor speed.
- Upgrade stations can improve machine efficiency and conveyor speed globally, with three paid levels each.
- Press X while aiming at a building to dismantle it; the building UI has the same action and refund amount.
