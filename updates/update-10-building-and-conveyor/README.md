# Update 10: Building copy and conveyor runs

- Middle mouse copies the targeted placed building and starts its build preview.
- Conveyor construction now uses a start click and an end click; the preview shows the route and estimated cost.
- Conveyor runs are assembled from connected segments with rails, rollers, belt surface and supports.
- Dust extractor and press use more detailed procedural low-poly models.

The visual direction was informed by Kenney's CC0 Conveyor Kit, which includes industrial conveyor models: https://kenney-assets.itch.io/conveyor-kit. Current meshes are procedural and authored in the project.
